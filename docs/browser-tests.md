# Браузерная регрессия popup

Из корня, после установки JDK 25, Node.js 22, Python 3.10+ и Docker/Compose:

```sh
make install-browser
make test-browser
```

Первая команда выполняет `npm ci` по `frontend/package-lock.json` и устанавливает
совместимый Chromium. На Linux могут потребоваться системные библиотеки браузера:
[официальная инструкция Playwright](https://playwright.dev/docs/browsers#install-system-dependencies).
Повторяй установку Chromium при обновлении Playwright. Для отдельного cache можно
задать `PLAYWRIGHT_BROWSERS_PATH` одинаково при установке и запуске.

`test-browser` создаёт уникальный Compose project с tmpfs PostGIS и случайным портом,
собирает JAR и запускает его на случайном localhost-порту. Миграции и demo применяются
как в приложении. Редактор и пароль генерируются только на время запуска.
Рабочая `.env`, `DB_*`, `TEST_DB_URL`, настройки редактора/профиля/listener и JVM
из пользовательского окружения не выбирают БД/приложение теста. Процесс приложения,
контейнер и временные данные удаляются также при обычном падении теста.

Тесты запускаются Node test runner с Playwright. `frontend/package.json` содержит
только инструменты браузерных тестов, не сборку frontend и не миграцию на Svelte.
Leaflet/Bootstrap загружаются так же, как в UI, из CDN; нужен сетевой доступ.
CDN/системная ошибка не считается успешной проверкой. Обычный `make verify`
не запускает Chromium: запускай обе команды перед изменением popup или рендеринга.

Проверяются три сценария:

- Название с `<b>`, кавычками, `&`, `<img onerror>` и `<svg onload>` вводится
  в черновик, сохраняется авторизованным UI, читается из БД после reload, открывается
  в popup точки, списке выбранных и popup расстояния. Сравнивается буквальный текст,
  отсутствие исполняемых DOM-элементов и значение индикатора выполнения JS.
- Для дорог и полигонов используются настоящие геометрии из demo API; перехват
  ответа заменяет только названия на вредоносную строку и `null`. Это проверка
  реального Leaflet-рендеринга, а не запись в импортированные таблицы.
- Сохраняются fallback «Без названия», две десятичные цифры и перенос строки
  расстояния. Popup закрывается клавишей Enter; scoped axe проверяет popup.

Это Chromium-регрессия конкретной границы вывода. Она не заменяет полный аудит
доступности legacy UI, проверку всех браузеров, тайлового сервиса или импортера.
Тесты отказываются запускаться без настроек временного контура; не направляй их
вручную на личную/рабочую БД.
