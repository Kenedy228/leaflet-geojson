через `git log --follow -- frontend/<file>`. Backend импортирован **снимком**
указанного commit, а не subtree-merge или submodule. Его прежние commits не
добавляются в локальную историю монорепозитория и доступны в исходном репозитории.
Для клонирования и сборки монорепозитория исходный backend-репозиторий не нужен.

## Изменения при переносе

- Пути frontend перенесены без изменения пользовательских сценариев.
- `constraints.js` использует относительный `/api/v1/osm`.
- Maven включает HTML/CSS/JavaScript из `frontend/` в static resources Spring Boot;
  backend-исходники и локальные файлы конфигурации в этот набор не входят.
- Исходные datasource-реквизиты не импортированы. Backend получает `DB_URL`,
  `DB_USER` и обязательный `DB_PASSWORD` из окружения; добавлен безопасный `.env.example`.
- Добавлены корневые Make-команды, README и актуализирован AGENTS.md.
- Добавлен интеграционный тест раздачи frontend и API с одного сервера.

Существующие зависимости, SQL-запросы и endpoints сохранены. Svelte, новая модель
данных, миграции, авторизация и исправление известных дефектов выполняются отдельно.
`infra/` будет добавлен вместе с реальным локальным окружением в #2.

## Проверка

Проверено 2026-11-01:

- `make check`: синтаксис всех frontend-скриптов и Git whitespace check.
- `make verify`: сборка JAR и 3 теста, 0 failures / 0 errors / 0 skipped.
  Новый тест сначала воспроизвёл 404 для `/`, затем прошёл после подключения ресурсов.
- Чистый Git-снимок текущего дерева без `target/` и `.env`: повторный `make verify`
  и запуск собранного JAR прошли с тем же временным PostGIS.
- HTTP smoke на JAR из чистого снимка: страница, все 9 JS/CSS-ресурсов и 6 API endpoints.
  Проверены типы геометрий, добавление/чтение/удаление точки и преобразование координат.
- Геодезическая проверка `[0,0] → [1,0] → [1,1]`: сегменты около
  111319.491 и 110574.389 м, сумма 221893.879 м, допуск 0.5 м.
- Браузерный smoke в Chromium: загрузка Leaflet и трёх геослоёв, выбор точек,
  расчёт и сброс дистанции, создание и удаление точки через UI; ошибок JavaScript нет.
- Независимое review переноса не выявило замечаний в рамках задачи #1.

Проверки выполнялись с отдельным временным PostGIS 17 / PostGIS 3.5
(`postgis/postgis:17-3.5`) и небольшими fixtures. Ни БД автора, ни её данные
не использовались. Fixtures предназначены для smoke-проверки совместимости SQL,
не заменяют миграции и утверждённую схему данных из #2/#7.

Системный Java runtime сообщал версию 25, но не содержал `ct.sym`, из-за чего
Maven выдавал `release version 25 not supported`. Проверки выполнены с полноценным
Eclipse Temurin JDK 25.0.5 и Maven 3.9.11 из временного каталога; версия Java
в `pom.xml` не менялась. Нужен полный JDK, одного runtime недостаточно.

Это проверка переноса и основных успешных сценариев. Найденные ранее дефекты,
авторизация, негативные и конкурентные сценарии остаются задачами roadmap.

После публикации объединённого кода нужно обновить описание исходного backend
ссылкой на монорепозиторий. До публикации такое перенаправление преждевременно.
Исходный backend не архивируется в рамках этой задачи.
